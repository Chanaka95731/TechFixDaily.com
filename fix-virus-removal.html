Remove Virus Without Antivirus: Manual Step-by-Step Guide

If your PC is heavily infected, a virus might block you from opening or downloading any antivirus software. When this happens, you have to fight back manually using Windows' built-in tools. Here is how to hunt down and destroy malware by hand.

Step 1: Enter Safe Mode with Networking

Viruses are programs. If Windows boots normally, the virus starts running and defends itself. Safe Mode prevents third-party apps from starting.

  1. Hold down the Shift key and click the Restart button in your Windows start menu.
  2. Your PC will boot to a blue screen. Click Troubleshoot > Advanced Options > Startup Settings > Restart.
  3. When it reboots, press 5 or F5 to enter Safe Mode with Networking.

Step 2: Kill the Virus in Task Manager

Now that we are in Safe Mode, we need to find the malicious process.

  1. Press Ctrl + Shift + Esc to open Task Manager. Click "More details" if necessary.
  2. Go to the Startup tab. Look for anything highly suspicious (e.g., weird names like "dsjhkjh.exe", programs with no publisher, or scripts). Right-click and select Disable.
  3. Go back to the Processes tab. If you see a suspicious process eating CPU, right-click it and select Open file location. (Do not close this folder window).
  4. Back in Task Manager, right-click the process and select End task.

Step 3: Delete the Malicious Files

Go to the folder window you opened in Step 2. Because you just killed the task, the file is no longer "in use" and can be deleted.

  1. Hold Shift and press Delete on the suspicious file to permanently delete it without sending it to the Recycle Bin.
  2. Common virus hiding spots: Check C:\Users\[YourName]\AppData\Local\Temp and delete everything inside the Temp folder.

Step 4: Clean the Registry (Advanced)

Malware often edits the registry to ensure it starts up again even if you delete the file.

  1. Press Win + R, type regedit, and press Enter.
  2. Navigate to this exact path: HKEY_CURRENT_USER\Software\Microsoft\Windows\CurrentVersion\Run
  3. Look at the entries on the right. If you see a key pointing to the virus file you just deleted, right-click the key and select Delete.
  4. Check the same location under HKEY_LOCAL_MACHINE as well.

Step 5: Run Windows Defender Offline Scan

Now that the virus is crippled, restart your PC normally. Immediately go to Settings > Update & Security > Windows Security > Virus & threat protection > Scan options. Select Microsoft Defender Offline scan and click Scan now. This will reboot your PC and let Defender scan the hard drive before Windows fully loads, wiping out any remnants.
